Graph Analysis

Use the 4-step reading strategy from 10A to analyze real data charts about globalization.

Academic literacy — disciplinary reading of data (Zwiers, 2014)
Remember from 10A: read the title → read the key/labels → read the axes → identify patterns and trends.

📊 4 Steps to Read a Graph

1

Read the title — What is this graph or chart about?

2

Read the key / labels — What do the colors, symbols, or labels mean?

3

Read the axes — What is on the vertical (up/down) axis? What is on the horizontal (left/right) axis?

4

Identify patterns and trends — Is it going up, going down, or staying the same? What does that tell us?
